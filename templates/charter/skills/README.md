# 技能库（skills）

> 把职责里反复用到的动作，变成有测试、有版本、可复用的能力包。

## 生命周期

| 状态 | 含义 | 进入条件 | 退出条件 |
| --- | --- | --- | --- |
| draft | 提取中的草稿 | 有真实使用场景 | 有测试用例 |
| testing | 真实工单中试用 | 至少 1 次真实使用 | 通过验收用例 |
| published | 可被岗位引用 | 版本 + Owner + 测试证据 | 被替代或失效 |
| deprecated | 退役 | 新版替代/场景消失 | 归档保留链接 |

**发布门槛**：`SKILL.md` 完整 + 验收用例 + 版本 + Owner + `registry.md` 登记。没有测试只能算 draft。

## 目录

```text
skills/<skill-name>/
├── SKILL.md
├── references/   # 可选
└── tests/        # 发布前必须有验收用例
```

## 与职责/知识的关系

职责的「技能」字段引用这里发布的技能名；技能里的判断标准来自 `KE/`；被证明是硬规则时写进宪章。
