# KE · 项目级知识库

> 两套规则：**P/A/R/T** 决定放哪，**MAKE** 决定收不收。

## P/A/R/T

| 层 | 放什么 | 判断问题 |
| --- | --- | --- |
| Project | 有起止的项目知识：决策、里程碑、教训 | 项目结束后还有用吗？ |
| Area | 长期领域：规范、口径、流程、常见问题 | 这是持续责任吗？ |
| Reference | 外部资料摘要与索引 | 是别人的资料，我们只索引？ |
| Task | 一次性解法：命令、脚本、排查步骤 | 下次能直接照做吗？ |

## MAKE 四性（至少满足 3 项；缺 Actionable 或 Experience 退回）

- **Minimal**：一条只讲一件事，一屏读完。
- **Actionable**：有步骤/命令/判断标准，能直接照做。
- **Knowledge**：解释为什么。
- **Experience**：来自真实工单/复盘，有来源与代价。

## 流程

采集（复盘/工单）→ 查重（先搜 `index.md`）→ 定位（P/A/R/T）→ 按模板写 → 过 MAKE → 登记索引 → 季度复核。

`KE/index.md` 是唯一入口；"生效"但不在索引里的条目视为未登记。过期或没人用的在月复盘清理。
