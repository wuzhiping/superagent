# 公共上下文（context）

> 团队当前共同认知的最短版本。长文进 `KE/`，原文链接回卡片/工单/复盘。

| 块 | 文件 | 回答 | 新鲜度 |
| --- | --- | --- | --- |
| A 最新复盘总结 | `retrospectives.md` | 最近一次复盘说了什么、哪些行动没关闭 | 复盘后 24h 内更新；≤7 天 |
| B 领域对象 | `domain/*.md` | 有哪些对象、什么关系、什么规则 | 每个对象有有效期 |
| C 组织本体 | `ontology/team-model.md` | 组织/岗位/职责/能力/价值流/对象怎么分层 | 每月对齐职责 |

**规则**：先读 context 再读原文；每条结论有来源；过期未复核视为不可信；同一知识只在 KE 存一份。
