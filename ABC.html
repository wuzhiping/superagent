入口

DSH → 左侧 超级智能体 → Team 视角 → 设置。按钮文字随界面语言（简/繁）变化，按同名找。

MINIMUM · 必填很少

只有 ★ 字段要填，其余全默认

Tab★ 必填其余（保持默认）
来源 · Kanban服务器、API key、项目（下拉选）、监听列 ready认领列/交付列/首次轮询/标签过滤
来源 · Gitea服务器、账号/密码、宪章仓库 owner/name宪章文件默认 README.md

宪章正文（5 行模板）发布者、历史自动记录
职责说明正文（1 段模板，承接岗位写 Worker）其余职责字段按模板
评估 / 执行接单模式=自动接单；模型可用时限、并行数、执行目录
TAB 1 · 来源

四张卡 = 四个家：任务 / 规则 / 文件 / 通知

卡片填什么（★）保存后看到
Kanban 看板服务器、API key、项目、监听列测试连接通过；项目可选
Gitea（宪章仓库）服务器、账号、宪章仓库、README.md连接通过，可读写宪章
ntfy 主题服务器、topic、入库 tagtopic 可订阅
MinIO 对象存储服务地址、桶、密钥（可留空）桶可读

OK 的样子

四张卡无红色报错；编队页来源状态正常。

小提示

保存来源后可能提示"正在重启/重连"几秒，正常，等恢复即可。

TAB 2 · 项目与岗位

选项目、加两个岗位（只填 ★ 三项）

项目

下拉里选项目，名称与 slug 自动带出；主题集可留空。

别手抄项目 id。

两个岗位

新增项目时默认已带一个 PM 岗位和一个 Worker 岗位；用不上的可删除。

只补三项：id pm-/w1-<项目>、登录邮箱；角色已选好。

监听列 ready、WIP 默认；页面底部保存档案。

OK 的样子：每张岗位卡下方出现「已映射到 Kanban 使用者 id：…」。

TAB 2 · 宪章

发布团队公约：复制 5 行就能用

目标：<这一期为客户创造什么>
流程：ready → in-progress → in-review → done
岗位：PM 派工、审进度、处理异常；Worker 执行与交付
交付：文档/方案放 MinIO；代码开 PR；卡片回写结果
异常：卡住 → 评论提问并转 blocked，进 PM 异常队列

动作

写正文 → 点发布宪章。

OK 的样子

版本号 ≥ v1，有发布时间与发布者；每周最多发布一版。

TAB 2 · 职责说明

发布任务说明书：1 段模板起步

### doc · 文档交付
- 承接岗位：w1-<项目>
- 目标：按卡片要求产出一份文档
- 完成：文件已上传并可回读，卡片回写文件位置
- 载体：MinIO 对象（deliverables/<项目>/<工单>/<文件>）
- 步骤：读宪章 → 读卡片 → 写文档 → 上传回读 → 报告

动作

编辑 → 点发布职责说明（提交到宪章仓库的 duties.md）。

OK 的样子

职责列表出现、条数正确；承接岗位写 Worker，不要写 PM。

TAB 3 · 评估

让系统自己接单：只动两个地方

设置怎么选含义
接单模式自动接单系统会自己评估并接单；"仅观察"只记录不接
研判模型默认可就不动；不可用则选一个系统判断"这单接不接"用的模型

还要看一眼

「在各来源上」的发起人名单里有团队账号（Kanban/Gitea/ntfy）。

OK 的样子

保存成功；接单模式显示自动接单；模型可用。

TAB 4 · 执行

确认谁来干、并行多少

设置建议说明
执行器模型可用即可；不可用则选一个真正干活用的模型
并行工单数1–2同时最多干几个活
执行目录 / 环境留空用默认无需手改

OK 的样子

保存成功；「编队」页/岗位视角显示执行器运行中、无红色报错。

怎么看

●

•

•

✓
8 项全绿 = 运行环境就绪，不用再翻页核对
CONTROL · 看到什么就是什么

状态字典：随时知道"现在怎样、要不要动手"

你看到的含义你要做什么
来源 正常 / ready这条路通了不用管
来源 暂停 / paused被关掉或还没配想用就打开并保存
来源 错误 / error地址、凭据或权限不对按提示改，再测一次
已映射到 Kanban 使用者 id：…系统知道卡派给谁不用管
宪章 v1 / v2…团队公约已生效每周复盘后最多改一版
职责说明 1 条 / N 条系统认得这几类活新增活法时再来加
接单模式 自动接单会自己接单开工不用管；观察演练可改"仅观察"
执行器 0 / 1，排队 0当前没有在跑的活不用管；有活时会动

SETUP TROUBLES · 按 tab 定位

设置阶段最常见的问题

现象多半在怎么办

项目下拉是空的来源 · 看板API key 无该工作区权限，或地址错
邮箱不在工作区成员里项目与岗位 · 岗位让同事先加入 Kanban 工作区
发布宪章失败项目与岗位 · 宪章Gitea 仓库无写权限，或仓库/文件名填错
模型显示"默认不可用"评估 / 执行选一个可用的服务商与模型
保存时提示冲突项目与岗位重新载入后再保存
